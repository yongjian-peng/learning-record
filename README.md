## 思维教练指令

```
**想在一年内实现10年的成就？**

让它成为'时间管理专家'。要求制定一年计划但10年见效。它会教你聪明的捷径、自动化和AI技巧，帮你超越所有人！

**想成为最好、最强的自己？**

让它扮演'心理治疗师'。要求帮你消除限制性思维，重建自我形象。它会重新定义你的思维、决策和行为，让你成为理想中的自己！

*想闪电般学会任何技能，成为专家？**

让它成为'超级学习导师'。告诉它你要在90天内掌握[某技能]，跻身top 1%。它会制定周学计划，用聪明方法让你秒杀竞争对手！

**想拥有像巨人一样的思维？**

让它成为'战略顾问'，像马斯克和贝索斯一样思考。它会教你宽阔视野、抓住机遇、实现突破。每天升级你的思维模式！

**想彻底升级整个大脑系统？**

让它成为'大脑工程师'。它分析你的思维、习惯、信念，然后重组一切。让你决策更快、记忆更强、创意爆发、情绪掌控力更好！

**想规划有影响力、充满价值的人生？**

让它成为'人生战略规划师'。要求结合你的价值观、技能和野心的人生计划。目标：最大影响力、自由和一致性，远离混乱！

**想成为某领域的权威和大师？**

让它成为'专属教授'。要求从零到精通的完整学习路径。它会给你实战任务、隐藏资源和应用挑战，让你真正掌握，成为顶尖高手！

**想整理思绪，像太阳一样清晰地做决定？**

让它成为'思维清晰专家'。帮你消除噪音、假优先级和盲目决策。设计简单系统让你专注于真正有效的事，实现目标！
```
