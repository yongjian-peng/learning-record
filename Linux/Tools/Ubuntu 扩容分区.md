# 进入系统



如果出现 `Configuration console-data` / 键盘设置，选择：

```
Don't touch keymap
```

![image-20260828131454579](E:\Git\learning-record\Linux\Tools\assets\image-20260828131454579.png)

如果要求选择语言：

```
Which language do you prefer?
```

保持默认英文即可，通常直接 Enter

如果出现：

```
Which mode do you prefer?
```

选择：

```
0
```

即 `Start X to use GParted automatically`，然后 Enter。
