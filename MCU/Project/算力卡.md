# 启动命令

```
cd ~/bm1684x-stress

MODEL="$HOME/bm1684x-stress/source/sophon-demo_v0.3.9_de46090_20260407/sample/ResNet/models/BM1684X/resnet50_fp32_1b.bmodel"

./bm1684x_stress.sh \
  --bmodel "$MODEL" \
  --duration 28800 \
  --temp-limit 85 \
  --board-temp-limit 75 \
  --threads 4 \
  --loopnum 1000000 \
  --devid 0
  
  参数说明：
参数	设置	作用
duration	14400	连续测试4小时
temp-limit	85°C	芯片温度停止阈值
board-temp-limit	75°C	板卡温度停止阈值
threads	4	4个推理线程
loopnum	1000000	每轮推理循环次数
devid	0	使用0号设备

bm-smi --opmode=display_memory_detail
```
