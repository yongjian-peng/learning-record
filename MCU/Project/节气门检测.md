# 开发环境

开发语言	C++17 / C++14
UI	Qt Widgets，优先于 QML
编译环境	Qt 5.15.x + MSVC 2019/2017，具体需根据 Win7 兼容性验证
示波器通信	VISA / USB-TMC / SCPI / 厂家 SDK，取决于示波器型号
STM32通信	USB 虚拟串口 / USB-UART，Qt SerialPort
波形显示	QCustomPlot / 自研 Qt 绘图 / 商业高速 Chart 库
本地数据库	SQLite
测试模板	SQLite + JSON
PDF报告	Qt PDF / HTML → PDF
Excel	CSV 优先；如果必须 .xlsx，使用 QXlsx
配置文件	JSON / INI
日志	spdlog / Qt logging
安装包	Inno Setup / NSIS

## 自动 OK / NG 判定

```
例如模板定义：

目标开度：50%
允许实际开度：48%～52%


Sensor1：
标准值 2.5V
允许值 2.4～2.6V

实际：

实际开度：50.3%       OK
Sensor1：2.48V        OK

最终：

本步骤：OK

如果：

Sensor1 = 2.75V

则：

Sensor1：NG
最终结果：NG

支持异常弹窗/结果提示。

该判断逻辑对应需求中的“标准参考值与反馈值比较、任意参数超阈值后显示是否合格”。
```
